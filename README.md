# Лабораторная работа №4

## Выполненные требования

- Подключен скрипт `script.js` к HTML-странице.
- Реализован ввод имени пользователя через `prompt` с обработкой значения по умолчанию.
- Создан массив громкости треков в децибелах (вариант №9, тема «Музыкант и звукорежиссёр»).
- Реализованы функции для обработки массива:
  - `findMax` — поиск максимального значения громкости;
  - `filterLoudTracks` — фильтрация треков с громкостью более 90 дБ;
  - `calculateSum` — вычисление суммарной громкости для нахождения среднего значения.
- С помощью цикла подсчитано количество тихих треков (не более 75 дБ) и их средняя громкость.
- Реализован вывод через `alert`: приветствие с именем, средняя громкость треков и количество громких треков.
- В консоль (`console.log`) выведено количество тихих треков и их средняя громкость.
- Реализовано дополнительное условие: предупреждение о защите слуха при наличии громкости 105 дБ и выше.

## Запуск

Откройте файл `index.html` в браузере. Для запуска алгоритма анализа громкости нажмите кнопку «Анализировать громкость треков» в разделе «Мои релизы». Откроется диалоговое окно ввода имени, затем окно `alert` с результатами, а подробные данные и предупреждение отобразятся в консоли разработчика (F12).
